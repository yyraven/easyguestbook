# EasyGuestBook

![](logo.png)

**EasyGuestBook** is a lightweight, serverless, Google Forms-powered guestbook designed for static blogs (natively built for Quarto, but adaptable anywhere).

## Features

- 🚫 **No backend required:** Hosts only need a standard Google account to manage everything.
- ✍️ **Rich text:** Markdown formatting and emojis are fully supported.
- 💬 **Interactive:** Includes built-in support for inline replies.
- 🎨 **Auto-styling:** Uses smart inline CSS to automatically adapt to your website's existing theme, fonts, and colors.
- 🪶 **Minimalist architecture:** Runs on just two files.
